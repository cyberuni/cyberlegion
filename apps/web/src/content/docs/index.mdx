## Why it looks like this

<CardGrid>
  <Card title="No MCP, no daemon" icon="rocket">
    Coordination is filesystem state under a shared hub root, reached through a shell command — not a server, a port, or a long-lived process.
  </Card>
  <Card title="Harness-agnostic" icon="laptop">
    Rides each harness's own session-start hook and speaks no vendor protocol, so every harness joins the same Legion with no per-harness glue.
  </Card>
  <Card title="Addressable units" icon="random">
    An `agent` is a definition, a `unit` is a running instance with its own mailbox, a `pane` is where it lives.
    [The spine →](/cyberlegion/concepts/spine/)
  </Card>
  <Card title="Agent-friendly output" icon="document">
    Token-efficient TOON by default, `--format json` as the escape hatch, structured errors, and definitive empty states.
  </Card>
</CardGrid>
